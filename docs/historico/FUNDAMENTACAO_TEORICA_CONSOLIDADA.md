# NEXUS — Fundamentação Teórica Consolidada

A versão acadêmica consolidada foi atualizada fora do repositório em PDF/DOCX e acompanha a evolução real do projeto.

## Alterações desta versão

- problema e pergunta de pesquisa preservados;
- rastreabilidade tratada como continuidade entre desenvolvimento e suporte;
- gestão do conhecimento conectada ao reuso de soluções validadas;
- IA generativa tratada teoricamente sem afirmar LLM real no MVP;
- RAG tratado como fundamento/evolução, não como funcionalidade implementada;
- alucinação e viés de automação usados para justificar validação humana;
- Angular 22 registrado como tecnologia efetivamente adotada;
- backend Django com SQLite (localhost) registrado como arquitetura de persistência;
- GitHub e Vercel registrados como infraestrutura efetivamente utilizada;
- trabalhos relacionados ampliados com Azure DevOps, Jira Service Management e ServiceNow;
- avaliação e indicadores delimitados para não confundir dados de demonstração com resultados experimentais;
- Parte 4 documentada como plano de implementação e critérios de conclusão.

## Regra de integridade acadêmica

A documentação não reescreve retroativamente a Fase 4 original. O documento original registrava localStorage e ausência de backend naquela fase. A adoção do backend Django é apresentada como evolução arquitetural posterior.
